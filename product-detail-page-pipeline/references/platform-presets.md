# Platform Presets

Treat these as planning defaults, not immutable platform policy. Confirm current marketplace requirements before final export.

## Amazon listing and A+

- Prefer 6–8 modules with low text density and strong evidence.
- Separate the main white-background listing image from A+ lifestyle and comparison modules.
- Avoid price, ratings, unsupported awards, competitor logos and unverifiable superlatives.
- Keep mobile readability in mind; important copy should remain legible when reduced.

## Shopify DTC

- Prefer 5–8 reusable modules: hero, problem/use case, proof, detail, comparison, package and FAQ/assurance.
- Let brand visual DNA lead, but keep product facts visually provable.
- Plan desktop and mobile crops rather than treating one long image as the only output.

## TikTok Shop

- Use mobile-first 1:1, 4:5 or 9:16 compositions according to the placement.
- Make product identity and use case understandable quickly.
- Keep copy concise and avoid UI elements that imitate platform controls.

## Taobao/Tmall

- A vertical narrative may use 8–10 screens or a stitched long page.
- Keep Chinese copy short and require the image model to render every quoted string verbatim inside each independently generated screen.
- Keep feature callouts tied to product evidence; avoid dense decorative text.

## Generic

When the platform is unknown, plan square/4:5 modular assets with safe margins. Keep exact copy in the prompt pack, render it directly in each independent screen, and preserve the original screens so later resizing or localization can regenerate only the affected modules.
