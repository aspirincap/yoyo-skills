# Creator Routes

## Generated Character

Use when the only reliable input is the product plus description, and the script should generate a new stable creator identity first.

Best for:

- one product image plus text description workflows
- creator-style UGC without a pre-existing talent asset
- adjacent-frame continuity pipelines
- wearable or handheld product demos with a consistent on-screen person

This is the default route in the new workflow.

## Existing Character Reference

Use when the user already has a reference image for the creator persona and wants the workflow to preserve that identity.

Best for:

- preserving a specific face
- branded creator avatars
- rerunning a concept with the same on-screen person
- reducing variance in keyframe generation

## Minimal Dry Run

Use when the user wants planning, prompts, and command manifests without paying generation costs.

Best for:

- pipeline verification
- prompt review
- debugging model availability
- preparing a run for later execution

Use `--dry-run`, optionally combined with `--heuristic-plan`.
