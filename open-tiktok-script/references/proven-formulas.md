# TikTok创意公式参考库

> 当用户未提供竞品视频时，作为首轮创意假设，而不是已验证的效果结论。使用前应结合当前市场、真实竞品证据或投放数据复核。新增公式时记录来源 URL、观察日期和证据强度。

## 通用 TikTok 创意逻辑

### 前2秒法则

TikTok开头不是一句口播，而是“画面动作 + 屏幕文字 + 口播语气”的组合。

**常用钩子组合**：

1. **POV + 具体麻烦**
   - `POV: your makeup looks good until you step outside.`
   - 适合美妆、穿搭、日用、办公、校园。

2. **Demo-first + 结果画面**
   - `I did not expect this tiny thing to work this well.`
   - 适合清洁、家居、工具、小家电。

3. **Comment reply + 产品演示**
   - `You asked if it actually works, so I tested it.`
   - 适合TikTok Shop和Spark Ads。

4. **Hot take + 纠错**
   - `Stop using this the way the package shows it.`
   - 适合教程、护肤、健身、效率工具。

5. **Bundle/offer + 视觉堆叠**
   - `This set is way better than I thought for the price.`
   - 适合组合装、赠品、TikTok Shop促销。

### 节奏模型

| 模型 | 描述 | 适用 |
|------|------|------|
| Hook-demo-proof-CTA | 开头给问题，马上演示，再补信任，最后购买引导 | TikTok Shop/Paid通用 |
| Comment reply | 用评论截图开头，像在回应真实问题 | Spark Ads/Organic |
| POV routine | 跟随创作者日常流程植入产品 | 日用、美妆、健康习惯 |
| Mistake-fix | 指出常见错误，展示更简单做法 | 教程、工具、护肤 |
| Before-after | 前后对比，但避免夸大承诺 | 美妆、收纳、清洁 |

### 通用转化路径

- Organic：停留钩子 → 真实场景 → 个人体验 → save/comment/follow。
- TikTok Shop：停留钩子 → 产品演示 → 价格/组合装 → tap product card。
- Spark Ads：达人原生钩子 → 体验/演示 → 轻CTA → 商品卡/落地页。
- Paid In-Feed：强视觉钩子 → 单一主卖点 → 证据 → 清晰CTA。

## 品类公式：美妆护肤

### 钩子公式

推荐测试组合：**POV/场景 + 半边脸或质地演示**

| 要素 | 推荐做法 |
|------|----------|
| 文案钩子 | `POV: your base looks perfect indoors... then this happens.` |
| 视觉钩子 | 半边脸对比、自然光切换、质地挤出、近景涂抹 |
| 信任来源 | 上脸演示、不同光线、真实肤感描述 |
| 风险边界 | 不承诺永久改变肤色、祛痘、治愈皮肤病；不制造肤色/年龄羞辱 |

**可复制句式**：
- `I tested this under the lighting that usually exposes everything.`
- `This is the part I actually care about: how it looks after a few hours.`
- `If your base separates around here, watch this.`

### 分镜结构（30秒）

| 阶段 | 时长 | 内容 | 视觉 |
|------|------|------|------|
| Hook | 0-2秒 | 场景痛点或反差 | 半边脸/自然光/镜前表情 |
| Demo | 2-10秒 | 上脸或质地演示 | 特写，字幕标注 |
| Proof | 10-20秒 | 持妆/肤感/遮瑕体验 | 不同角度和光线 |
| Offer/CTA | 20-30秒 | 商品卡/组合/购买理由 | 手持产品+字幕CTA |

### 合规与语气

- 用 `helped my skin look...`、`my base looked...`，少用确定性功效。
- 避免 `anti-aging miracle`、`fixes acne`、`whitens skin`。
- 不把皱纹、肤色、痘痘、年龄说成“丢脸”或“必须遮掉”的缺陷。

## 品类公式：家居清洁/收纳

### 钩子公式

推荐测试组合：**messy before + satisfying demo**

| 要素 | 推荐做法 |
|------|----------|
| 文案钩子 | `I found the one thing that made this corner less chaotic.` |
| 视觉钩子 | 凌乱画面→快速整理、污渍→擦除、抽屉→整齐 |
| 信任来源 | 一镜到底演示、前后对比、真实使用声音 |
| 风险边界 | 不伪造效果，不用无法证明的“kills 99.9%”除非产品资料支持 |

**可复制句式**：
- `This took me less time than finding the thing I needed.`
- `Watch this drawer go from chaos to actually usable.`
- `I thought it was a gimmick, but this part is useful.`

### 分镜结构（20-30秒）

| 阶段 | 时长 | 内容 | 视觉 |
|------|------|------|------|
| Hook | 0-2秒 | messy before | 俯拍或快速推进 |
| Demo | 2-14秒 | 使用过程 | 手部动作、ASMR、快切 |
| Result | 14-22秒 | before/after | 同角度对比 |
| CTA | 22-30秒 | 商品卡/购买理由 | 产品+使用场景 |

## 品类公式：健康习惯/营养补充

### 钩子公式

推荐测试组合：**日常场景 + 轻体验表达**

| 要素 | 推荐做法 |
|------|----------|
| 文案钩子 | `This is the tiny step I added to my morning routine.` |
| 视觉钩子 | 倒水、冲泡、开瓶、放进包里、日常流程 |
| 信任来源 | 成分含量、使用场景、口味/便利性、真实routine |
| 风险边界 | 不承诺治疗、减重、睡眠、焦虑改善等确定结果；不替代医疗建议 |

**可复制句式**：
- `I keep this in my bag for the days my routine gets messy.`
- `It tastes like something I'd actually finish.`
- `For me, the convenience is the whole point.`

### 分镜结构（25秒）

| 阶段 | 时长 | 内容 | 视觉 |
|------|------|------|------|
| Hook | 0-2秒 | routine切入 | 早晨/办公室/健身包 |
| Product | 2-8秒 | 产品出现 | 开瓶/冲泡/包装特写 |
| Benefit | 8-18秒 | 便利、口味、成分 | 字幕列3点 |
| CTA | 18-25秒 | 购买路径 | 商品卡/组合装 |

### 合规与语气

- 用 `supports`、`helps me stay consistent`、`part of my routine`。
- 避免 `cures`、`fixes anxiety`、`guaranteed sleep`、`lose weight fast`。
- 避免对身材、心理健康、疾病状态做羞辱式钩子。

## 品类公式：时尚/穿搭

### 钩子公式

推荐测试组合：**fit problem + try-on montage**

| 要素 | 推荐做法 |
|------|----------|
| 文案钩子 | `I needed one top that works with half my closet.` |
| 视觉钩子 | 快速换装、镜前转身、细节拉近 |
| 信任来源 | 多身材/多场景试穿、面料细节、尺码建议 |
| 风险边界 | 不做body shaming，不暗示某身材“糟糕/不该露” |

**可复制句式**：
- `This is how I styled it three ways.`
- `The fabric is the reason it looks more expensive than it is.`
- `If you like a more relaxed fit, I would size up.`

### 合规与语气

- 用“fit、comfort、coverage、silhouette”讲体验。
- 避免“hide your body/fix your shape/real women”等排除或羞辱表达。

## 公式使用指南

### 有竞品视频时

1. 先用视频分析接口分析竞品视频。
2. 对照本文件，看竞品使用了哪个钩子和结构。
3. 提炼适合产品与目标市场的creator angle。
4. 生成脚本时同时参考竞品分析和本文件。

### 无竞品视频时

1. 根据产品品类选择最接近公式。
2. 没有完全匹配时，使用“通用 TikTok 创意逻辑”。
3. 首轮输出至少给3个hook变体，方便用户测试。
4. 提醒用户后续用真实竞品或投放数据迭代。

### 新增品类

每次完成竞品分析后，将新品类公式追加到本文件，格式与现有品类保持一致。
